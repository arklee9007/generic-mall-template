# 配置口径

## 店铺配置（settings.shopConfig，后台「系统设置」里改）

| 键 | 含义 | 默认值 |
|---|---|---|
| brandWord | 品牌字（显示在店头） | 空 |
| brandColor | 主色（十六进制，如 #2563EB） | #2563EB |
| logo | Logo 图片地址 | 空 |
| footerText | 页脚文字 | 空 |
| specAxes | 规格轴名，至多 3 项 | ["规格一","规格二","规格三"] |
| specChart.enabled | 是否显示规格说明表 | true |
| specChart.title | 规格说明表标题 | 规格说明 |
| reviewRequired | 三段闸：是否需要人工审核 | true（默认开，买家可关） |
| member.enabled | 会员总开关 | true |
| member.rechargeEnabled | 充值开关 | true |
| member.packages | 充值套餐 [{amount 分, bonus 分, label}] | 10000/0、20000/2000、50000/8000 |

轴名三级回落：商品 specLabels[i] → 全局 specAxes[i] → 默认「规格一/二/三」。轴显隐只看商品对应数组是否为空，不看标签。

## 会员档位（member_tiers 表，后台「会员管理」里改）

每档：等级（1-20）、名称、累计充值实付门槛（分）、折扣（基点，10000=不打折，如 9500=95折）、卡背景图（商家上传）、卡文字、排序、启用。

定级口径：只按累计充值实付（赠送不计），只升不降；档位被删时，已定级的顾客自动回落到不高于其等级的最高现存档。充值开关关时顾客不能充值、等级只由后台手动指定；会员总开关关时全店无会员（不显示会员价与会员卡入口）。

充赠口径：只认整额命中的套餐（充 20000 命中 20000 档得赠送，充 25000 不命中任何档则无赠送）。充值金额范围 100 分至 100000000 分。

## 退款分路

- 按件退款：source（各回各路：余额部分回余额，上限为该单余额支付额减已退余额部分，其余走原路）或 balance（全部退余额），默认 source。
- 整单退款：original（等价于 source）或 balance（全部退余额），默认 original。

## 三段闸

商品流：上新池 → 货架待审核 → 人工审核通过才激活。reviewRequired 关掉后，商品进货架即自动通过审核。前端可见须同时满足：进货架 + 已激活 + 上架。

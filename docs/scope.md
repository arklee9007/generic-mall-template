# 可编辑收口、售后边界与已知限制

## 可编辑只到三类

1. 参数：店名、品牌字、主色、Logo、页脚文字、规格轴名、运费模板、会员档位与套餐、开关。
2. 内容：商品、分类、轮播、公告、FAQ、首页区块显隐与顺序、客服话术。
3. 开关：会员总开关、充值开关、审核开关、规格说明开关。

不到页面结构、版式与钱账逻辑。想要不同结构、不同版式、不同计价退款规则，走定制档另行报价。

## 售后边界（边界售后，非零售后）

负责：包不全（缺文件）、部署说明有错、程序 bug。
不负责：改需求、运营手把手教学、买家自改代码后出的问题、第三方平台（微信、CloudBase）政策与故障。

## 已知限制

- 导航蓝图标为静态 SVG 文件，改主色后图标不变色，属已知限制。
- 小程序端主色通过构建期配置生效，改主色后须重新编译上传；H5 与后台改主色即时生效。
- 演示数据图片为中性占位图，清空演示数据后须自行上传商品图。
- 规格说明表为通用表格（列与行自定义），不含服装行业默认的尺码推荐内容。
- 真实支付与短信默认关闭（realPaymentEnabled/smsEnabled），接通真实支付走定制。
- 自动化功能（自动上新、自动上下架）不在本包内，另售加购包。
